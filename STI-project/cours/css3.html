0. Définition & Règles de Priorité (Cascading)
💡

Définition du Sélecteur

Un sélecteur CSS est le motif utilisé pour cibler et désigner les éléments HTML auxquels on souhaite appliquer des règles de style.

</> Structure d'une règle CSS
sélecteur {
  propriété: valeur;
}
1

Priorité selon l'Emplacement

Ordre d'application du style du plus prioritaire au moins prioritaire :

1er (Gagne) Style en ligne : style="..."
2ème Style interne : <style>
3ème Style externe : .css lié
4ème Navigateur (Style par défaut)
2

Priorité entre Sélecteurs (Spécificité)

  • 🥇 !important : Écrase toutes les autres règles.
  • 🥈 ID (#id) : Poids très fort (100).
  • 🥉 Classe (.class), Pseudo-classe (:hover) : Poids moyen (10).
  • 🔹 Élément (h1, p, div) : Poids faible (1).
1. Types des Sélecteurs & Pseudo-Classes
1

Sélecteurs de Base

*, elem, #id, .class
  • 🔹 * : Sélectionne tout.
  • 🔹 #id : Élément unique par identifiant.
  • 🔹 .class : Tous les éléments de cette classe.
2

Sélecteurs d'Attributs

element[attr]
  • 🔹 [href^="#"] : Commençant par "#".
  • 🔹 [href$=".org"] : Finissant par ".org".
3

Pseudo-Classes d'État

:hover, :active, :visited
  • 🔹 :hover : État au survol du pointeur.
  • 🔹 :active : État lors du clic/pression.
🔗

Combinaison de Sélecteurs

  • 🔹 .cl1.cl2 (Sans espace) : Élément possédant simultanément les deux classes.
  • 🔹 .cl1 .cl2 (Avec espace) : Descendants .cl2 à l'intérieur de .cl1.
  • 🔹 .cl1 > .cl2 : Enfants directs de premier niveau.
.box.active { color: red; }
✍️

Pseudo-Élément ::first-letter

Permet de cibler et styliser spécifiquement la première lettre d'un bloc de texte.

p::first-letter { font-size: 2em; color: #2e86de; }
Les 4 états d'un lien — a:link, a:visited, a:hover, a:active
🔗

Les 4 États d'un Lien <a>

  • 🔹 a:link : cible tous les liens non visités.
  • 🔹 a:visited : cible tous les liens visités.
  • 🔹 a:hover : cible l'élément au moment où l'utilisateur le survole avec le pointeur de la souris.
  • 🔹 a:active : cible tous les liens activés (pendant le clic).
</> Ordre d'écriture — règle « LoVe / HAte »
a:link    { color: #2e86de; } /* L : non visité */
a:visited { color: #8e44ad; } /* V : visité */
a:hover   { color: #e2691a; } /* H : survolé */
a:active  { color: #d6336c; } /* A : cliqué */
👁 Résultat interactif (survolez puis cliquez)
Lien de démonstration

5. Positionnement & Flexbox
A

Nature des balises

inline

Éléments qui, par défaut, restent sur la même ligne que leurs voisins.

Quelques balises
<span><a><strong> <em><b><i> <img><label>
B

Nature des balises

block

Éléments qui, par défaut, commencent sur une nouvelle ligne et prennent toute la largeur.

Quelques balises
<div><p><section> <article><h1>…<h6> <ul> / <li><form><header>

ℹ️ Chaque balise HTML a une nature par défaut (inline ou bloc) définie par le navigateur, mais on peut la changer avec la propriété display.

Rappel — display : inline / block / inline-block
1

Affichage

display: inline

L'élément reste sur la même ligne et se dimensionne selon son contenu.

  • ✅ Pas de retour à la ligne.
  • ✅ N'occupe que la largeur de son contenu.
  • ❌ width / height ne fonctionnent pas.
  • ✅ margin-left/right fonctionnent, margin-top/bottom limité.
👁 Résultat
Bonjour tout le monde

Les deux éléments restent sur la même ligne.

2

Affichage

display: block

L'élément commence sur une nouvelle ligne et prend toute la largeur disponible par défaut.

  • ✅ Retour à la ligne automatique.
  • ✅ Occupe toute la largeur disponible.
  • ✅ width / height fonctionnent.
  • ✅ margin et padding fonctionnent entièrement.
👁 Résultat
Bloc 1
Bloc 2

Chaque élément commence sur une nouvelle ligne.

3

Affichage

display: inline-block

Un mélange des deux : reste sur la même ligne comme inline, mais accepte les dimensions comme block.

  • ✅ Reste sur la même ligne.
  • ✅ width / height fonctionnent.
  • ✅ margin et padding fonctionnent entièrement.
  • ✅ Très utile pour boutons, menus, étiquettes.
👁 Résultat
Bouton 1 Bouton 2

Même ligne + possibilité de définir largeur et hauteur.

Les 5 fiches — Position & Flex
1

Position relative

position: relative

L'élément reste à sa place dans le flux normal, mais on peut le décaler visuellement avec top, left, etc. Son espace d'origine reste réservé.

  • ✅ Reste dans le flux normal du document.
  • ✅ top / right / bottom / left le déplacent visuellement.
  • ✅ Sert de repère pour un enfant en absolute.
  • ✅ z-index fonctionne.
  • ⚠️ L'espace d'origine reste réservé.
</> Exemple CSS
.box {
  position: relative;
  top: 14px;
  left: 8px;
}
👁 Résultat
place d'origine
Élément

L'élément se déplace, mais son emplacement de départ reste réservé.

2

Position absolute

position: absolute

L'élément sort du flux et se positionne par rapport à son plus proche ancêtre positionné (relative/absolute/fixed/sticky), sinon par rapport à la page.

  • ✅ Sort du flux : les autres éléments l'ignorent.
  • ✅ Se cale sur le parent positionné le plus proche.
  • ✅ top/right/bottom/left permettent de le placer.
  • ✅ Idéal pour badges, tooltips et superpositions.
  • ⚠️ Sans parent positionné → se cale sur la page.
</> Exemple CSS
.carte { position: relative; }
.badge {
  position: absolute;
  top: -8px; right: -8px;
}
👁 Résultat
.carte (relative) Badge

Le badge se cale sur le coin de la carte grâce au parent relative.

3

Position fixed

position: fixed

L'élément sort du flux et se positionne par rapport à la fenêtre du navigateur. Il reste visible même quand la page défile.

  • ✅ Sort du flux normal.
  • ✅ Fixe par rapport à la fenêtre (viewport), pas à la page.
  • ✅ Reste visible pendant le défilement.
  • ✅ Utile pour une barre de navigation ou un bouton « haut de page ».
  • ⚠️ Un ancêtre avec transform peut changer son repère.
</> Exemple CSS
.barre {
  position: fixed;
  bottom: 10px; right: 10px;
}
👁 Résultat
Zone de page qui défile…
ligne 1 · ligne 2 · ligne 3 📌 Fixe

Dans la page réelle, l'élément reste ancré au même endroit du viewport.

4

Position sticky

position: sticky

Un mélange de relative et fixed : l'élément suit le flux normal, puis se « colle » dès qu'il atteint le seuil défini.

  • ✅ Reste dans le flux.
  • ✅ Se comporte comme relative, puis se fixe au seuil.
  • ✅ Nécessite au moins un top/bottom/left/right.
  • ✅ Parfait pour en-têtes de tableau et titres de section.
  • ⚠️ Limité à la zone de son conteneur parent.
</> Exemple CSS
.entete {
  position: sticky;
  top: 0;
}
👁 Résultat
📌 En-tête collant
Ligne 1
Ligne 2
Ligne 3
Ligne 4
Ligne 5

L'en-tête reste visible en haut de sa zone pendant le défilement.

5

Display flex

display: flex

Ce n'est pas une valeur de position, mais un mode d'affichage qui aligne et répartit les enfants sur une ligne ou une colonne.

  • ✅ Aligne les enfants sur une ligne ou colonne.
  • ✅ justify-content gère l'axe principal.
  • ✅ align-items gère l'axe transversal.
  • ✅ gap espace les éléments proprement.
  • ✅ Idéal pour menus, cartes et formulaires alignés.
</> Exemple CSS
.conteneur {
  display: flex;
  justify-content: space-between;
  gap: 10px;
}
👁 Résultat
1
2
3

Les éléments se répartissent et s'alignent automatiquement dans le conteneur.

Tableau comparatif

⚖️ Comparaison des 5 comportements

Critère relative absolute fixed sticky flex
🔀 Reste dans le flux ? ✅ Oui ❌ Non ❌ Non ✅ Oui ✅ Oui
📍 Se positionne par rapport à… sa position normale parent positionné le plus proche la fenêtre (viewport) son conteneur + seuil de scroll — (organise ses enfants)
📐 Nécessite top/right/bottom/left ? Optionnel Selon le placement Selon le placement ✅ Oui (au moins un) ❌ Non
📌 Reste visible au défilement ? ❌ Non ❌ Non ✅ Oui ✅ Oui, une fois collé — Non concerné
🧱 z-index utile ? ✅ Oui ✅ Oui ✅ Oui ✅ Oui — Non concerné

ℹ️ flex n'est pas une valeur de position mais une valeur de display : elle est ajoutée ici car souvent confondue avec les positions pour organiser une mise en page.

🎯 À retenir

  • 1️⃣RELATIVE → reste dans le flux, avec décalage possible.
  • 2️⃣ABSOLUTE → sort du flux, par rapport au parent positionné.
  • 3️⃣FIXED → sort du flux, par rapport à la fenêtre.
  • 4️⃣STICKY → reste dans le flux puis se colle au seuil.
  • 5️⃣FLEX → organise et aligne les enfants.

⭐ Astuces mnémotechniques

sticky = relative jusqu'au seuil + comportement collant après le seuil.

absolute = pense d'abord au parent positionné, souvent relative.

flex = organisation des enfants, pas une position de l'élément lui-même.

7.2 Listes — puces & numérotation (list-style)
🔢

Forme des puces — list-style-type

Définit la forme de la puce d'une liste non ordonnée (ul) ou le style de numérotation d'une liste ordonnée (ol).

👁 Quelques valeurs
  • disc
  • disc
  • circle
  • circle
  • square
  • square
  1. decimal
  2. decimal
  1. upper-roman
  2. upper-roman
  • none
  • none
ul { list-style-type: square; }
ol { list-style-type: upper-roman; }
📍

Position de la puce — list-style-position

Précise si la puce se place à l'extérieur ou à l'intérieur du bloc de texte.

👁 outside (défaut) vs inside

list-style-position: outside;

  • La puce est en dehors du texte.
  • Les lignes s'alignent proprement.

list-style-position: inside;

  • La puce fait partie du texte.
  • Le retour à la ligne rentre sous la puce.
ul { list-style-position: inside; }
🖼️

Puce en image — list-style-image

Remplace la puce classique par une image.

ul { list-style-image: url("puce.svg"); }
👁 Avec une puce SVG
  • Puce personnalisée n°1
  • Puce personnalisée n°2
  • Puce personnalisée n°3
  • ⚠️ Si l'image ne charge pas, la puce de list-style-type prend le relais.
  • 🔹 Peu de contrôle (taille, alignement) : pour un rendu précis, utilisez background-image sur les li.
🧩

Super-propriété — list-style

Regroupe type, position et image en une seule déclaration — l'ordre est libre.

ul { list-style: upper-roman inside; }
ul { list-style: square inside url("puce.svg"); }
👁 Résultat combiné
  • Type + position + image en une seule ligne.
  • Les valeurs omises reviennent à leur valeur par défaut.
  • 🔹 S'applique sur ul / ol et s'hérite par les li.
  • 🔹 En cas de conflit, list-style-image gagne sur list-style-type (tant que l'image charge).
8. Filtres, Transformations 2D détaillées & Animations
🔄

Propriété transform et Fonctions Associées (Annexe)

Permet d'appliquer des effets géométriques 2D ou 3D à un élément sans modifier le flux normal. Fonctions principales :

  • 📍 rotate() : Rotation (ex: transform: rotate(90deg);).
  • 📐 skew() : Inclinaison horizontale/verticale (ex: transform: skew(30deg);).
  • 🔍 scale() : Échelle d'agrandissement/réduction (ex: transform: scale(2);).
  • 🚚 translate() : Déplacement à l'aide d'un vecteur (ex: transform: translate(120px);).
.box-transform:hover { transform: rotate(15deg) scale(1.1); }
