Activité 1 : Généralités et Rôle de JavaScript

  • Chemin critique du rendu : Le navigateur analyse d'abord le HTML pour créer le DOM (Document Object Model) et le CSS pour le CSSOM[cite: 5]. La combinaison des deux produit l'arbre de rendu (Render Tree), qui permet ensuite le calcul des positions (Layout) et le dessin à l'écran (Paint)[cite: 5].
  • Rôle Côté Client : Manipule dynamiquement la structure HTML et le CSS via l'API DOM, réagit aux événements utilisateur (clics, survol) et contrôle la validité des données saisies dans les formulaires[cite: 5].
  • Rôle Côté Serveur : Avec Node.js, JavaScript peut aussi s'exécuter sur le serveur pour gérer les bases de données, les accès fichiers et la logique métier[cite: 5].

Activité 2 : Emplacement du Code & Analyse de la Figure

  • Emplacement du Script : En-tête du document (entre les balises <head> et </head>)[cite: 5].
  • Déclenchement : Événement onclick situé dans la balise HTML <a>[cite: 5].
  • Analyse de la figure :
    • <script> ... </script> : Balises d'insertion du code JS[cite: 5].
    • function action() : Entête de déclaration d'une fonction[cite: 5].
    • var age = prompt(...) : Déclaration d'une variable locale et boîte de saisie interactive[cite: 5].
    • if (...) { ... } else { ... } : Structure conditionnelle complète (Alternative)[cite: 5].
    • alert(...) : Boîte de dialogue d'affichage de message d'avertissement[cite: 5].
    • return true / return false : Valeur de retour envoyée à l'appelant[cite: 5].
