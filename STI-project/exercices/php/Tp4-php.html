Série d'Exercices : Connexion et manipulation avec MySQLi (Procédural / Objet)

Soit une base de données nommée ecole contenant une table etudiant dont la structure est la suivante :

  • etudiant (numetu INT PRIMARY KEY, nometu VARCHAR(50), moyenne FLOAT)

Travail Demandé

  1. Écrire un script PHP de connexion à la base de données ecole située sur le serveur local (localhost), avec le nom d'utilisateur root et sans mot de passe, en utilisant l'API **MySQLi (orientée objet ou procédurale)**. Le script doit tester si la connexion a échoué et afficher un message d'erreur explicite le cas échéant.
  2. Écrire un script PHP qui permet d'insérer un nouvel étudiant dans la table etudiant (par exemple : Numéro = 101, Nom = "Mohamed", Moyenne = 14.5) en utilisant la fonction mysqli_query() ou la méthode équivalente.
  3. Écrire un script PHP qui exécute une requête de sélection (SELECT) pour récupérer tous les enregistrements de la table etudiant.
    • Parcourir le résultat à l'aide d'une fonction de parcours (ex: mysqli_fetch_assoc()).
    • Afficher les informations de chaque étudiant sous forme de tableau HTML.
  4. Modifier le script précédent pour afficher uniquement les étudiants dont la moyenne est supérieure ou égale à 10.
  5. Écrire un script PHP qui permet de fermer proprement la connexion à la base de données ouverte précédemment en utilisant la fonction adéquate.
