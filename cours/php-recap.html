Transtypage : conversion de type

Le transtypage consiste à convertir une valeur vers un autre type : entier (int), réel (float), chaîne (string) ou booléen (bool).

Valeur à convertir :
$v = (int) "12.8abc";

Exemples : (int) 12.8 donne 12 ; (float) "12.8" donne 12.8 ; (string) 25 donne "25" ; (bool) "0" donne false. Attention : convertir n'est pas valider une donnée.

Fonctions arithmétiques

abs() — valeur absolue
$n = abs(-15);
echo $n; // 15

Renvoie la distance à zéro : abs(-7.5) donne 7.5.

sqrt() — racine carrée
$n = sqrt(81);
echo $n; // 9

sqrt(2) donne environ 1.4142. Pour une valeur négative, le résultat réel n'est pas défini.

round() — arrondir
round(3.6); // 4
round(3.14159, 2); // 3.14

Le deuxième argument indique le nombre de chiffres après la virgule.

rand() — nombre pseudo-aléatoire
$n = rand(1, 6);
echo $n; // entier de 1 à 6

Les deux bornes sont incluses. Pour un tirage sécurisé, utiliser plutôt random_int().

La fonction date() et les formats

En PHP, date() reçoit une chaîne de format. Les lettres sont sensibles à la casse : Y et y n'ont pas le même sens.

echo date("Y-m-d"); // 2026-10-09
echo date("y-m-d"); // 26-10-09
echo date("d-m-Y"); // 09-10-2026
echo date("d/m/Y"); // 09/10/2026
echo date("H:i:s"); // heure:minutes:secondes
CodeSignificationExemple
YAnnée sur 4 chiffres2026

jJour sans zéro initial9

Sélectionnez un format puis cliquez.

Attention : les tirets et les barres obliques sont des séparateurs littéraux. Par exemple, date("Y-m-d") donne année-mois-jour, tandis que date("y-m-d") donne la même structure mais avec l'année sur 2 chiffres. Le résultat réel dépend de la date et du fuseau horaire du serveur PHP.
