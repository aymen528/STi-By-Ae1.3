Chapitre 1

Éléments d'en-tête et de 1er niveau

Balises essentielles à la structure fondamentale et aux métadonnées d'un document HTML5.

Balise Description & Attributs
<html> Racine du document HTML. Contient les éléments <head> et <body>. Attribut recommandé : lang="fr".
<head> Fournit les informations générales (métadonnées) sur le document : titre, scripts, feuilles de style CSS.
<body> Contient tout le contenu visible de la page web (textes, images, liens, tableaux, formulaires).
<link> Définit la relation entre le document et une ressource externe (ex: fichier CSS, favicon).
Attributs : href, rel (ex: "stylesheet"), type ("text/css").
<meta> Représente des métadonnées (encodage charset="UTF-8", configuration du viewport mobile name="viewport").
<script> Intègre ou référence du code exécutable (généralement JavaScript).
Attributs : src (URI du script), type.
<style> Définit des règles de style CSS directement au sein du document HTML.
<title> Spécifie le titre de la page affiché dans la barre de titre ou l'onglet du navigateur.
Exemple d'en-tête HTML5 Exemple PDF Page 1 
<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Le fleuriste du Rafèha</title>
    <link rel="stylesheet" href="styles.css" type="text/css" />
    <script src="controles.js"></script>
  </head>
  <body>
    <!-- Contenu principal -->
  </body>
</html>
Chapitre 2

Éléments de structuration de page web et conteneurs

Balises sémantiques introduites avec HTML5 pour organiser la disposition d'une page.

<header>

Conteneur pour le contenu d'introduction ou un groupe de liens de navigation.

<nav>

Définit une section contenant les liens de navigation principaux du site.

<main>

Spécifie le contenu principal et unique du document (exclusion des pieds de page/sidebars récurrents).

<section>

Définit une section logique et thématique dans un document.

<article>

Spécifie un contenu autonome et indépendant (ex: article de blog, fiche produit).

<aside>

Définit un contenu secondaire en dehors du contenu principal (souvent placé en barre latérale).

<footer>

Définit le pied de page d'un document ou d'une section (droits d'auteur, contacts, liens de retour).

<div> / <span>

<div> : conteneur générique de type block.
<span> : conteneur générique de type inline.

<iframe>

Définit un cadre en ligne (cadre de sous-navigation permettant d'intégrer une autre page HTML).

Attributs clés : src (URL de la page intégrée), name, width, height.

Chapitre 3

Listes à puces et ordonnées

Structure de présentation sous forme d'éléments énumérés.

<ul>

Définit une liste non ordonnée (à puces).

<ol>

Définit une liste ordonnée (numérotée).

<li>

Définit un élément dans une liste (<ul> ou <ol>).

Attributs spécifiques de la balise <ol> :

  • reversed : Attribut booléen. Indique que les éléments sont numérotés dans l'ordre inverse.
  • type : Définit le type de numérotation : • 1 : Chiffres arabes (par défaut)
    • a / A : Lettres minuscules ou majuscules
    • i / I : Chiffres romains minuscules ou majuscules
  • start : Entier spécifiant la valeur de départ de la numérotation (ex: start="4" commence à "D" ou "4").
Exemple extrait du PDF (Page 2)
<ol start="2" type="I">
  <li>Choix Fleurs</li>
  <li>Achat</li>
</ol>
Chapitre 4

Tableaux de données

Structure complète pour présenter des données sous forme de grilles et colonnes.

<table> : Conteneur global
<caption> : Titre/Légende
<thead> : Entête du tableau
<tbody> : Corps du tableau
<tfoot> : Pied du tableau
<tr> : Ligne du tableau
<th> : Cellule d'en-tête
<td> : Cellule de données
Structure complète d'un tableau (Page 3)
<table border="1">
  <caption>Tableau de choix</caption>
  <thead>
    <tr>
      <th>Fleurs disponibles</th>
      <th>Fleurs Choisie (s)</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Orchidées</td>
      <td>Tulipa</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">Tous droits réservés par Lycée Rafèha</td>
    </tr>
  </tfoot>
</table>
Chapitre 5

Éléments de texte et multimédia

Balises d'enrichissement de contenu textuel, liens et composants audio/vidéo.

<p> Définit un paragraphe de texte.
<h1> à <h6> Titres de niveau 1 (principal) à 6.
<hr> Ligne horizontale (rupture thématique).
<br> Saut de ligne simple.
<a> Lien hypertexte (href, target="_blank").
<cite> Spécifie le titre d'une œuvre référencée.
<mark> Texte mis en surbrillance.
<address> Coordonnées d'un auteur ou propriétaire.
<details> / <summary> Bloc dépliant avec titre visible.
<output> Conteneur pour résultats de calculs JavaScript.

Multimédia avancé : Images, Vidéos & Figures

<img>

Intègre une image.
Attributs: src, alt, width, height.

<figure> & <figcaption>

Conteneur autonome d'illustration avec sa légende explicative associée.

<audio> & <video>

Lecteurs multimédias natifs.
Attributs: controls, src, width.

Exemple Vidéo + Figures (Page 4)
<figure>
  <figcaption>
    <cite>Tous droits réservés par </cite> Lycée RAfèha
  </figcaption>
  <video controls width="250">
    <source src="media/flower.webm" type="video/webm" />
    <source src="media/flower.mp4" type="video/mp4" />
    Votre navigateur ne prend pas en charge les vidéos HTML5.
  </video>
</figure>
Chapitre 6

Attributs globaux et événements JavaScript

Attributs universels et déclencheurs d'actions utilisateur.

Attributs Globaux Principaux

class : Nom(s) de classe(s) CSS
id : Identifiant unique de l'élément
style : Règles CSS en ligne
title : Bulle d'information d'aide
hidden : Masque l'élément
lang : Code de langue du contenu

Événements (Page 5)

Événement Description du déclenchement
onclickAu moment du clic de souris sur l'élément.
onblur / onfocusQuand l'élément perd / obtient le focus clavier ou curseur.
oninput / onchangeDès que la valeur est modifiée ou validée.
onloadLorsque la page ou la ressource est totalement chargée.
onmouseover / onmouseoutLorsque le pointeur de la souris entre / sort de la zone.
onplay / onpauseDébut ou mise en pause d'une lecture multimédia.
onsubmitLorsqu'un formulaire est soumis.
onkeydown / onkeyupPresse ou relâchement d'une touche du clavier.
Chapitre 7

Éléments de formulaire et types d'Input

Composants de saisie de données utilisateur et leurs attributs de validation.

<form>

Attributs : action, method ("get", "post"), target.

<fieldset> / <legend>

Regroupe des éléments liés avec un titre/légende associé.

<select> / <option>

Crée une liste déroulante d'options sélectionnables.

<datalist>

Définit une liste d'options prédéfinies pour un <input>.

<textarea>

Zone de texte multiligne.
Attributs : cols, rows, placeholder, required, maxlength.

Types de balises <input> (Page 6)

Types d'élément Attributs génériques Attributs spécifiques
button, reset, submit name, value, disabled -
text, email, tel name, value, placeholder, readonly, required, disabled, list -
password name, value, placeholder, readonly, required, disabled -
number, range name, value, readonly, required, disabled min, max
date, time name, value, required, disabled min, max
checkbox, radio name, value, required, disabled checked
Exemple complet de formulaire HTML5 (Page 6)
<fieldset>
  <legend><mark>Remplir le formulaire</mark></legend>
  
  <label for="nom">Nom et prénom: </label>
  <input type="text" name="nom" id="nom">
  
  <input type="email" name="email" id="email" placeholder="Votre @ mail">
  
  <label for="age">Votre Age: </label>
  <input type="range" name="age" id="age" min="10" max="120">
  <output name="resultatage">ans</output><br>
  
  <label for="pays">Pays : </label>
  <input type="text" id="pays" list="pays_disponibles">
  <datalist id="pays_disponibles">
    <option value="Tunisie">Tunisie</option>
    <option value="Algérie">Algérie</option>
    <option value="France">France</option>
    <option value="Italie">Italie</option>
  </datalist>
</fieldset>

<select name="fp" id="fp" size="3">
  <option value="Orchidées">Orchidées </option>
  <option value="Tulipa">Tulipa</option>
  <option value="Paeonia">Paeonia </option>
</select>

<textarea name="remarques" cols="25" rows="12" placeholder="n'hésitez pas si vous avez des remarques !!!"></textarea>
