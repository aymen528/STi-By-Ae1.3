1. Introduction au langage PHP

1.1 Définition

PHP (abréviation de Personal Home Page Hypertext Preprocessor) est un langage de scripts qui s'intègre aux pages HTML et qui permet de réaliser des pages Web dynamiques.

Un langage est dit « côté serveur » lorsque son code est exécuté sur le serveur Web, avant l'envoi de la page au navigateur. Le navigateur ne reçoit jamais le code PHP : il ne reçoit que le résultat, sous forme de HTML « classique ». C'est ce qui distingue PHP d'un langage « côté client » comme JavaScript.

1.2 Le principe client / serveur — en schémas

Analogie n°1 — Le client, le serveur et le chef cuisinier (au restaurant)

Le client ne voit jamais la recette ni la cuisine : il reçoit seulement le plat fini — de même que le navigateur ne reçoit jamais le code PHP, seulement le HTML généré.

Analogie n°2 — Le client au guichet d'une banque

Le client ne voit jamais le système interne — seulement le résultat final, comme l'internaute ne reçoit que la page HTML finale.

1.3 Syntaxe générale d'un script PHP

<?php
   // instructions PHP ici
   echo "Bonjour tout le monde !";
?>

Chaque instruction se termine par ;, les commentaires s'écrivent avec // ou /* ... */.

6. Fonctions de date et d'heure

Un timestamp est un entier long contenant le nombre de secondes écoulées entre le début de l'époque UNIX (1ᵉʳ janvier 1970 à 00:00:00 GMT) et une date donnée. Sur un site dynamique, on est souvent amené à : affecter la date/l'heure système à une variable, ajouter une période à une date, changer le format d'affichage d'une date, ou traiter des champs de type date.

Fonction Rôle (annexe)
checkdate() Vérifie la validité d'une date
date() Formate une date et la retourne sous forme de chaîne
time() Retourne l'heure actuelle en nombre de secondes
strtotime() Transforme une chaîne contenant une date en timestamp

6.1 checkdate — vérifier une date

Syntaxe : int checkdate(int m, int j, int a)

Retourne TRUE si la date représentée par le jour j, le mois m et l'année a est valide, sinon FALSE. Attention : l'ordre des arguments n'est pas l'ordre français (mois, jour, année). La date est valide si l'année est comprise entre 1 et 32767, le mois entre 1 et 12, et le jour dans l'intervalle du mois — les années bissextiles sont prises en compte. 

<?Php
$j=24; $m=9; $a=2026;
if (checkdate($m,$j,$a)==true) $d=$j."/".$m."/".$a;
else $d="données invalide ";
echo($d);
?>

6.2 date — formater une date

Syntaxe : string date(string format, [int timestamp])

Retourne une date sous forme de chaîne, au format donné par le paramètre format (ex. Y = année, m = mois, d = jour, H = heures, i = minutes, s = secondes). La date utilisée est celle du timestamp fourni, ou la date/heure courantes si aucun timestamp n'est fourni. 

<?Php
$d=date("Y-m-d H:i:s");
echo("Nous sommes le : ".$d);
?>

6.3 getdate — informations détaillées sur une date

Syntaxe : array getdate([int timestamp])

Retourne un tableau associatif contenant les informations de date et d'heure du timestamp fourni (ou de la date/heure courante sinon). Le tableau comporte les éléments : seconds, minutes, hours, mday, wday, mon, year, yday, weekday, month. 

<?php
$a=getdate();
$b=date("d-m-Y H:i:s");
echo("Nous sommes le : ".$b."<br>");
echo("Les secondes : ".$a["seconds"]."<br>");
echo("Les minutes : ".$a["minutes"]."<br>");
echo("Les heures : ".$a["hours"]."<br>");
echo("Le jour du mois : ".$a["mday"]."<br>");
echo("Le jour de la semaine : ".$a["wday"]."<br>");
echo("Les mois : ".$a["mon"]."<br>");
echo("L'année : ".$a["year"]."<br>");
echo("Le jour de l'année : ".$a["yday"]."<br>");
echo("Le nom du jour de la semaine : ".$a["weekday"]."<br>");
echo("Le nom du mois : ".$a["month"]."<br>");
?>

6.4 time — timestamp de l'instant présent

Syntaxe : int time(void)

Retourne le timestamp qui est un entier long représentant l'heure courante, mesurée en secondes depuis le 1ᵉʳ janvier 1970. 

<?Php
$a=time();
$b=date("d/m/Y H:i:s",$a);
echo($a." = ".$b);
?>

6.5 mktime — construire un timestamp

Syntaxe : int mktime(int hour, int min, int sec, int month, int day, int year, int is_dst)

Retourne un timestamp correspondant aux arguments fournis. Les arguments peuvent être omis de droite à gauche ; tout argument manquant prend la valeur courante de l'heure ou du jour. is_dst vaut 1 si l'heure d'été est appliquée, 0 sinon, et -1 (par défaut) si on ne sait pas. 

<?Php
$h=10; $mn=30; $s=0; $m=9; $j=24; $a=2026;
$ns=mktime($h,$mn,$s,$m,$j,$a);
echo("le nombre de secondes est : ".$ns."<br>");
$d=date("d-m-Y H:i:s",$ns);
echo("Ce nombre de secondes correspond à la date : ".$d);
?>

6.6 strtotime — interpréter une date en anglais

Syntaxe : int strtotime(string time, [int now])

Essaie de lire une date au format anglais et de la transformer en timestamp, relativement au timestamp now, ou à la date courante si celui-ci est omis. Accepte aussi des expressions relatives comme "+1 day", "+1 week". 

<?php
$a=strtotime("now");
$b=strtotime("10 September 2026");
$c=strtotime("+1 day");
$d=strtotime("+1 week");
$e=strtotime("+1 week 2 days 4 hours 2 seconds");

echo (date("Y-d-m H:i:s",$a)." = ".$a." secondes<br>") ;
echo (date("Y-d-m H:i:s",$b)." = ".$b." secondes<br>") ;
echo (date("Y-d-m H:i:s",$c)." = ".$c." secondes<br>") ;
echo (date("Y-d-m H:i:s",$d)." = ".$d." secondes<br>") ;
echo (date("Y-d-m H:i:s",$e)." = ".$e." secondes<br>") ;
?>

8.1 Le circuit d'une requête, étape par étape

        

          1. Connexion —
          mysqli_connect(hôte, utilisateur, mot_de_passe) ouvre une
          connexion au serveur MySQL et retourne une ressource de connexion (ex.
          $connexion).
        

        

          2. Sélection de la base —
          mysqli_select_db($connexion, "nom_bd") indique sur quelle
          base travailler.
        

        

          3. Construction de la requête SQL — la requête (SELECT, INSERT,
          UPDATE, DELETE…) est écrite dans une chaîne PHP, avec les valeurs des
          variables insérées.
        

        

          4. Exécution —
          mysqli_query($connexion, $requete) envoie la requête au
          serveur ; elle retourne un résultat (SELECT) ou true/false
          (INSERT/UPDATE/DELETE).
        

        

          5. Exploitation du résultat — pour un SELECT, on parcourt les
          lignes avec mysqli_fetch_array() dans une boucle
          while.
        

        

          6. Fermeture — mysqli_close($connexion) libère la
          connexion en fin de script.

          8.3 mysqli_query() : un comportement différent selon la requête
        

        

          Syntaxe :
          mixed mysqli_query(mysqli $connexion, string $requete).
          Cette fonction envoie n'importe quelle requête SQL au serveur, mais ce
          qu'elle retourne dépend du type de requête :
        

        

          Pour un SELECT (ou SHOW, DESCRIBE…) — elle retourne un objet
          mysqli_result : un « résultat » qu'il faut ensuite parcourir
          avec mysqli_fetch_array() ou
          mysqli_fetch_row(). En cas d'erreur de syntaxe SQL, elle
          retourne false.
        

        

          Pour un INSERT / UPDATE / DELETE — il n'y a pas de lignes à
          lire : elle retourne simplement true (succès) ou
          false (échec). On connaît alors l'effet de la requête via
          mysqli_affected_rows() ou
          mysqli_insert_id(), jamais via
          mysqli_fetch_array().
        

        
<?php
// SELECT : mysqli_query retourne un résultat à parcourir
$res = mysqli_query($connexion, "SELECT nom FROM eleves");
if ($res) {
   while ($ligne = mysqli_fetch_array($res)) {
      echo $ligne["nom"] . "<br>";
   }
} else {
   echo "Erreur SQL : " . mysqli_error($connexion);
}

// INSERT : mysqli_query retourne true / false
$ok = mysqli_query($connexion, "INSERT INTO eleves (nom) VALUES ('Sami')");
if ($ok) {
   echo "Insertion réussie, id = " . mysqli_insert_id($connexion);
} else {
   echo "Erreur SQL : " . mysqli_error($connexion);
}

// UPDATE : mysqli_query retourne aussi true / false
$ok2 = mysqli_query($connexion, "UPDATE eleves SET moyenne = 16 WHERE nom = 'Sami'");
if ($ok2) {
   echo mysqli_affected_rows($connexion) . " ligne(s) mise(s) à jour.";
}
?>


        
8.4 mysqli_fetch_array() et mysqli_fetch_row()

        

          mysqli_fetch_array($resultat) extrait la ligne courante
          du résultat et avance automatiquement au suivant à chaque appel ; par
          défaut elle retourne un tableau
          à la fois associatif et numérique (indices texte
          et indices entiers pour la même valeur), tant qu'il reste des
          lignes, sinon null.
        

        

          mysqli_fetch_row($resultat) fait la même chose mais
          retourne uniquement un tableau indexé numériquement (comme un
          tableau classique 0, 1, 2…), sans les clés textuelles.
        

        
<?php
$res = mysqli_query($connexion, "SELECT nom, moyenne FROM eleves");

// Avec mysqli_fetch_array : accès par nom de colonne OU par indice
$ligne = mysqli_fetch_array($res);
echo $ligne["nom"];      // accès associatif : "Ali"
echo $ligne[0];           // accès numérique : "Ali" (même valeur)
echo $ligne["moyenne"];   // "14.5"
echo $ligne[1];           // "14.5"

// Avec mysqli_fetch_row : accès uniquement par indice numérique
$res2 = mysqli_query($connexion, "SELECT nom, moyenne FROM eleves");
while ($row = mysqli_fetch_row($res2)) {
   echo $row[0] . " a pour moyenne " . $row[1] . "<br>";
   // $row["nom"] n'existerait pas ici : uniquement $row[0], $row[1]...
}
?>

        

          En pratique, mysqli_fetch_array() est le plus utilisé en
          classe car $ligne["colonne"] rend le code plus lisible ;
          mysqli_fetch_row() est plus léger quand on connaît déjà
          l'ordre exact des colonnes.
        


        
8.5 mysqli_num_rows()

        

          Syntaxe : int mysqli_num_rows(mysqli_result $resultat).
          Elle retourne le nombre de lignes contenues dans un résultat de
          type SELECT. Elle ne s'applique qu'à un résultat de SELECT (un objet
          mysqli_result) — pour connaître le nombre de lignes
          touchées par un INSERT/UPDATE/DELETE, on utilise
          mysqli_affected_rows() à la place.
        

        
<?php
$req = "SELECT * FROM eleves WHERE moyenne >= 10";
$resultat = mysqli_query($connexion, $req);
$nb = mysqli_num_rows($resultat);

if ($nb == 0) {
   echo "Aucun élève admis.";
} else {
   echo $nb . " élève(s) admis :<br>";
   while ($ligne = mysqli_fetch_array($resultat)) {
      echo "- " . $ligne["nom"] . "<br>";
   }
}
?>

8.7 Insérer, mettre à jour, supprimer

        
<?php
// INSERT
$req = "INSERT INTO eleves (nom, moyenne) VALUES ('Ali', 14.5)";
mysqli_query($connexion, $req);
echo "Nouvel id : " . mysqli_insert_id($connexion);

// UPDATE
$req2 = "UPDATE eleves SET moyenne = 15 WHERE nom = 'Ali'";
mysqli_query($connexion, $req2);
echo mysqli_affected_rows($connexion) . " ligne(s) modifiée(s).";

// DELETE
$req3 = "DELETE FROM eleves WHERE nom = 'Ali'";
mysqli_query($connexion, $req3);
mysqli_close($connexion);
?>

        

          Sécurité : toujours contrôler/échapper les données saisies par
          l'utilisateur avant de les insérer dans une requête SQL, afin d'éviter
          les injections SQL. Les anciennes fonctions mysql_* (sans
          « i ») sont obsolètes : utiliser MySQLi.
