<datalist>

Cours HTML5 — Liste de suggestions pour les champs de formulaire

Définition Syntaxe Option Types Comparaison

1. Définition de <datalist>

L'élément <datalist> permet de définir une liste de suggestions associée à un élément <input>.

Lorsque l'utilisateur commence à saisir une valeur, le navigateur peut afficher les valeurs proposées.

À retenir :
<datalist> fournit des suggestions, mais ne constitue pas une liste obligatoire de choix.

Exemple

<input type="text"
       list="villes">

<datalist id="villes">

    <option value="Tunis">
    <option value="Sousse">
    <option value="Sfax">

</datalist>

2. Association entre <input> et <datalist>

La liaison entre les deux éléments se fait avec :

  • list dans <input>
  • id dans <datalist>
<input list="monId">

<datalist id="monId">

    ...

</datalist>
Règle fondamentale :

list = id

La valeur de list doit être identique à la valeur de id du datalist.

3. L'élément <option>

Les suggestions du <datalist> sont définies avec des éléments <option>. 

<datalist id="villes">

    <option value="Tunis">
    <option value="Sousse">
    <option value="Sfax">

</datalist>

L'élément <option> peut être écrit de plusieurs manières.

4. Cas 1 : value = texte affiché

Dans ce cas, la valeur de l'attribut value est identique au texte contenu dans <option>. 

<option value="Tunis">Tunis</option>
<option value="Sousse">Sousse</option>
<option value="Sfax">Sfax</option>

On a donc :

value = "Tunis"
texte = "Tunis"

5. Cas 2 : value ≠ texte

Ici, le texte visible et la valeur envoyée par le champ peuvent être différents. 

<option value="TN">Tunisie</option>
<option value="DZ">Algérie</option>
<option value="MA">Maroc</option>

Par exemple :

Texte value
Tunisie TN
Algérie DZ
Maroc MA
Attention :
Le comportement exact de l'affichage des suggestions peut varier selon le navigateur lorsque value et le texte sont différents.

6. Cas 3 : value seulement

Il est possible de ne pas mettre de texte entre <option> et </option>. 

<option value="Tunis">
<option value="Sousse">
<option value="Sfax">

Ici, seule la valeur est définie :

value = "Tunis"
texte = aucun

7. Cas 4 : texte seulement

L'attribut value peut également être absent. On écrit simplement le texte entre les balises <option>. 

<option>Tunis</option>
<option>Sousse</option>
<option>Sfax</option>

Dans ce cas, le texte de l'option sert de valeur de l'option lorsqu'aucun attribut value n'est fourni.

8. Les quatre possibilités

Écriture value Texte Exemple
value = texte Présent Présent <option value="Tunis">Tunis
value ≠ texte Présent Présent <option value="TN">Tunisie
value seulement Présent Absent <option value="Tunis">
texte seulement Absent Présent <option>Tunis</option>
Point important :

Pour une utilisation pédagogique simple, le cas value = texte est généralement le plus facile à comprendre.

9. <datalist> avec différents types de <input>

🔤 text

🔢 number

🎚️ range

📅 date

⏰ time

📆 month

10. <datalist> ou <select> ?

<datalist> <select>
Propose des suggestions Propose des choix
L'utilisateur peut généralement saisir une autre valeur L'utilisateur choisit parmi les options proposées
Associé à un <input> Élément de formulaire autonome
Utilise list + id Contient directement les <option>

Avec datalist

<input list="villes">

<datalist id="villes">
    <option value="Tunis">
    <option value="Sousse">
</datalist>

Avec select

<select>

    <option>Tunis</option>
    <option>Sousse</option>

</select>

11. Synthèse du cours

1. <datalist> contient des suggestions.

2. Il est associé à un <input>.

3. list de l'input doit correspondre au id du datalist.

4. Les suggestions sont définies avec <option>.

5. value peut être identique ou différent du texte.

6. value peut être utilisé seul.

7. Le texte peut être utilisé sans attribut value.

8. On peut utiliser datalist avec plusieurs types d'input.

12. Exemple final complet

<form>

    <label>Ville :</label>

    <input
        type="text"
        name="ville"
        list="villes"
    >

    <datalist id="villes">

        <option value="TN">Tunisie</option>
        <option value="DZ">Algérie</option>
        <option value="MA">Maroc</option>

    </datalist>


    <label>Heure :</label>

    <input
        type="time"
        name="heure"
        list="heures"
    >

    <datalist id="heures">

        <option value="08:00">
        <option value="10:00">
        <option value="14:00">

    </datalist>


    <label>Mois :</label>

    <input
        type="month"
        name="mois"
        list="mois"
    >

    <datalist id="mois">

        <option value="2026-01">
        <option value="2026-06">
        <option value="2026-09">

    </datalist>

</form>
