Qu'est-ce que JavaScript ?

JavaScript est un langage de programmation qui s'exécute dans le navigateur (côté client). Il permet de rendre une page HTML dynamique et interactive : réagir aux clics, valider un formulaire, modifier le contenu ou le style d'un élément, faire des calculs, etc.

Où placer le code JavaScript ?

Script interne

Dans une balise <script>, en général juste avant </body>. 

<body>
  ...
  <script>
    alert("Bonjour !");
  </script>
</body>

Script externe

Le code est écrit dans un fichier .js séparé, plus facile à réutiliser. 

<script src="script.js"></script>

Script en ligne (inline)

Directement dans un attribut d'événement HTML. À réserver aux tests rapides. 

<button onclick="alert('Clic !')">
  Cliquer
</button>

Variables : portée et déclaration

Règles de nommage

Ces règles valent aussi pour les noms de fonctions.

  • Doit commencer par une lettre, $ ou _ — jamais par un chiffre
  • Peut ensuite contenir lettres, chiffres, $, _ — pas d'espace ni d'accent
  • Sensible à la casse : age ≠ Age
  • Ne peut pas être un mot réservé (let, function, if…) 
let age = 15;        // ✔ valide
let _total = 0;       // ✔ valide
let $prix = 9.9;       // ✔ valide
let nombre2 = 4;        // ✔ valide

let 2nombre = 4;   // ✘ commence par un chiffre
let mon age = 15;  // ✘ contient un espace
let let = 1;         // ✘ mot réservé

Locale ou globale ?

Une variable globale est accessible partout dans le script. Une variable locale n'existe qu'à l'intérieur de la fonction (ou du bloc) où elle est déclarée. 

let compteur = 0; // globale

function incrementer() {
  let pas = 1;     // locale à la fonction
  compteur += pas;
}

incrementer();
console.log(compteur); // 1 — accessible
console.log(pas);      // erreur — pas n'existe pas ici

Critère let var const
Portée Le bloc { } La fonction entière Le bloc { }

let : changer sa valeur dans un bloc

Tout dépend si on écrit un nouveau let dans le bloc ou non.

Sans nouveau let → on modifie la variable existante, le changement reste après le bloc : 

let x = 10;
if (true) {
  x = 20; // pas de "let" → même variable
}
console.log(x); // 20

Avec un nouveau let → une variable locale au bloc est créée, distincte de celle de l'extérieur : 

let y = 10;
if (true) {
  let y = 20; // "let" → nouvelle variable, propre au bloc
  console.log(y); // 20 (la variable du bloc)
}
console.log(y); // 10 (inchangée en dehors du bloc)

isNaN() vs Number.isNaN()

Comportement "blabla"
isNaN() Convertit d'abord en nombre true
Number.isNaN() Teste strictement, sans conversion false

Number.isNaN() est plus robuste.

Number(ch)

Number("37");       // 37
Number("blabla");   // NaN
Number(true);        // 1
Number(null);         // 0
Number(undefined);   // NaN

parseInt(ch [, base])

La base par défaut n'est pas 10 — toujours la préciser. 

function roughScale(x, base) {
  const parsed = Number.parseInt(x, base);
  if (Number.isNaN(parsed)) { return 0; }
  return parsed * 100;
}
roughScale('0xF', 16); // 1500
roughScale('321', 2);  // 0

parseFloat(ch)

function circumference(r) {
  if (Number.isNaN(Number.parseFloat(r))) { return 0; }
  return parseFloat(r) * 2.0 * Math.PI;
}
circumference('4.567abcdefgh'); // 28.695...
circumference('abcdefgh');      // 0

Encore quelques exemples

parseInt("42px");      // 42  (s'arrête au 1er caractère non numérique)

parseFloat("3.99abc"); // 3.99
parseInt("101", 2);     // 5   (binaire → décimal)
parseInt("FF", 16);     // 255 (hexadécimal → décimal)

Math

Cliquez sur une fonction pour afficher son détail.

Math.abs(x)
Valeur absolue de x (x sans son signe). 
Math.abs(-5);    // 5
Math.abs(3.2);   // 3.2
Math.abs(0);     // 0
Math.sqrt(x)
Racine carrée de x. Renvoie NaN si x est négatif. 
Math.sqrt(16);   // 4
Math.sqrt(2);    // 1.4142135623730951
Math.sqrt(-4);   // NaN
Math.round(x)
Entier le plus proche de x. Pour une partie décimale de .5, arrondit vers le haut (+∞). 
Math.round(2.4);   // 2
Math.round(2.5);   // 3
Math.round(2.6);   // 3
Math.round(-2.5);  // -2
Math.round(-2.6);  // -3
Math.trunc(x)
Retire la partie décimale de x, sans arrondir. 
Math.trunc(4.9);    // 4  (round donnerait 5)
Math.trunc(-4.9);   // -4 (round donnerait -5)
Math.trunc(7);      // 7
Math.random()
Réel aléatoire dans [0, 1[ (0 inclus, 1 exclu). Combiné à Math.trunc(), il donne un entier aléatoire. 
Math.random();                             // ex. 0.5327…
Math.trunc(Math.random() * 10);            // entier de 0 à 9
Math.trunc(Math.random() * 6) + 1;         // entier de 1 à 6 (dé)
Math.trunc(Math.random() * (max - min + 1)) + min; // de min à max

Chaînes de caractères (ch : objet String)

+ Concaténation
ch.length Longueur de ch
ch.indexOf(ch1 [,p]) Position de la 1ère occurrence de ch1 (sinon -1)
ch.lastIndexOf(ch1 [,p]) Position de la dernière occurrence de ch1
ch.substring(d, f) Sous-chaîne — voir détail ci-dessous
ch.replace(ch1, ch2) Remplace la 1ère occurrence de ch1 par ch2
ch.toLowerCase() Convertit en minuscules
ch.toUpperCase() Convertit en majuscules
ch.trim() Supprime les espaces en début/fin
String.fromCharCode(n1,…) Chaîne à partir de codes ASCII/UTF-16

Cliquez sur une fonction pour afficher son détail.

+
Concatène (colle bout à bout) deux chaînes. Si l'un des opérandes est une chaîne, l'autre est converti en chaîne. 
let prenom = "Aymen";
"Bonjour " + prenom;   // "Bonjour Aymen"
"Note : " + 15;        // "Note : 15"
5 + "5";               // "55"

Attention à l'ordre des opérandes : voir la carte « Nombre + chaîne » plus bas.

ch.length
Propriété (sans parenthèses) : nombre de caractères de ch, espaces compris. 
let s = "Mozilla";
s.length;                 // 7
"".length;                // 0
s[s.length - 1];          // "a" (dernier caractère)

Les indices vont de 0 à length - 1.

ch.indexOf(ch1 [, p])
Position de la première occurrence de ch1, en cherchant à partir de l'indice p (0 par défaut). Renvoie -1 si absente. Sensible à la casse. 
let s = "Bonjour tout le monde";
s.indexOf("o");        // 1
s.indexOf("o", 2);     // 4  (recherche à partir de l'indice 2)
s.indexOf("tout");     // 8
s.indexOf("z");        // -1 (absente)
s.indexOf("bon");      // -1 (casse différente)
ch.lastIndexOf(ch1 [, p])
Position de la dernière occurrence de ch1. La recherche se fait de la fin vers le début, en partant de l'indice p (fin de ch par défaut). Renvoie -1 si absente. 
let s = "Bonjour tout le monde";
s.lastIndexOf("o");      // 17
s.lastIndexOf("o", 10);  // 9  (on ignore ce qui est après l'indice 10)
s.lastIndexOf("z");      // -1
ch.substring(d [, f])
Extrait les caractères de l'indice d (inclus) à l'indice f (exclu). 
var s = "Mozilla";
s.substring(0,3);  // "Moz"
s.substring(3,0);  // "Moz" (inversé)
s.substring(4,7);  // "lla"
s.substring(4);    // "lla"
s.substring(0,6);  // "Mozill"
s.substring(0,10); // "Mozilla"

Règles : d = f → chaîne vide · f omis → jusqu'à la fin · négatif ou NaN → 0 · valeur > length → length · d > f → les deux valeurs sont interverties.

ch.replace(ch1, ch2)
Remplace la première occurrence de ch1 par ch2. Renvoie une nouvelle chaîne : ch n'est pas modifiée. 
let s = "a-b-c";
s.replace("-", "+");   // "a+b-c" (une seule occurrence)
s;                     // "a-b-c" (inchangée)
s = s.replace("-", "+"); // pour conserver le résultat
ch.toLowerCase()
Renvoie ch convertie en minuscules (ch n'est pas modifiée). 
"TUNIS Ariana".toLowerCase();  // "tunis ariana"

Pratique pour comparer sans tenir compte de la casse.

ch.toUpperCase()
Renvoie ch convertie en majuscules (ch n'est pas modifiée). 
"Tunis Ariana".toUpperCase();  // "TUNIS ARIANA"
ch.trim()
Supprime les espaces au début et à la fin de ch. Les espaces intérieurs sont conservés. 
"   salut  le monde  ".trim();  // "salut  le monde"

Utile pour nettoyer la saisie d'un prompt() ou d'un champ de formulaire.

String.fromCharCode(num, …, numN)
Méthode appelée sur String (et non sur ch) : construit une chaîne à partir de codes ASCII / UTF-16. 
String.fromCharCode(65,66,67); // "ABC"
String.fromCharCode(97);       // "a"
String.fromCharCode(0x2014);   // "—"
String.fromCharCode(8212);     // "—"

Nombre + chaîne : attention à l'ordre !

Avec +, dès qu'une chaîne apparaît, JavaScript convertit et concatène ; s'il n'y a que des nombres, il additionne. 

5 + "5";        // "55"  (entier + chaîne → concaténation)
"5" + 5;        // "55"  (chaîne + entier → concaténation)
5 + 5;          // 10    (entier + entier → addition)
5 + 5 + "5";    // "105" (addition d'abord, puis concaténation)
"5" + 5 + 5;    // "555" (concaténation depuis le début)
"Note : " + 15; // "Note : 15"

Appeler une fonction depuis le HTML

En pratique, une fonction n'est presque jamais appelée « toute seule » dans le script : elle est déclenchée par un événement HTML (onclick, onchange…).

Nommer une fonction

Une fonction suit les mêmes règles de nommage qu'une variable (voir plus haut) : commence par une lettre, $ ou _, pas d'espace ni de mot réservé. 

function calculerMoyenne() { ... } // ✔
function 2emeFonction() { ... }     // ✘ commence par un chiffre

Appel avec ou sans return

Critère Avec return Sans return
Résultat Une valeur exploitable undefined
Utilisation Dans une expression : let x = f(); Seule, comme instruction : f(); 
function carre(n) {
  return n * n;       // renvoie une valeur
}
let resultat = carre(4); // resultat vaut 16
alert(carre(5));         // utilisable directement

function afficherMessage() {
  alert("Bonjour !"); // ne renvoie rien
}
let x = afficherMessage(); // x vaut undefined
afficherMessage();          // s'utilise seule

19Écrire une fonction qui inverse un tableau sans utiliser de méthode native. 
function inverserTableau(tab) {
  let res = [];
  for (let i = tab.length - 1; i >= 0; i--) {
    res.push(tab[i]);
  }
  return res;
}

22Calculer l'âge exact d'une personne (années) à partir de sa date de naissance saisie, avec l'objet Date. 
let naissance = new Date(prompt("Date de naissance (AAAA-MM-JJ) :"));
let aujourdhui = new Date();
let age = aujourdhui.getFullYear() - naissance.getFullYear();
if (aujourdhui.getMonth() < naissance.getMonth() ||
   (aujourdhui.getMonth() == naissance.getMonth() && aujourdhui.getDate() < naissance.getDate())) {
  age--;
}
alert("Âge : " + age + " ans");
23Afficher le nombre de jours restants avant la fin de l'année scolaire (date cible fixe). 
let finAnnee = new Date("2027-06-30");
let aujourdhui = new Date();
let jours = Math.round((finAnnee - aujourdhui) / (1000 * 60 * 60 * 24));
alert(jours + " jours restants");

25Créer une checklist (cases à cocher) et compter, via getElementsByName, le nombre de cases cochées. 
<input type="checkbox" name="case"> A
<input type="checkbox" name="case"> B
<input type="checkbox" name="case"> C
<button onclick="compter()">Compter</button>

<script>
function compter() {
  let cases = document.getElementsByName("case");
  let n = 0;
  for (let c of cases) { if (c.checked) n++; }
  alert(n + " case(s) cochée(s)");
}
</script>

27Créer une liste déroulante de couleurs ; au changement, appliquer la couleur choisie au fond de la page (selectedIndex + style.background). 
<select id="couleur" onchange="changer()">
  <option value="white">Blanc</option>
  <option value="lightblue">Bleu</option>
  <option value="lightgreen">Vert</option>
</select>

<script>
function changer() {
  let sel = document.getElementById("couleur");
  document.body.style.background = sel.options[sel.selectedIndex].value;
}
</script>
