Exercice — Carte bancaire animée

Formulaire de paiement interactif avec retournement 3D

Face avant (saisie en cours)
Face arrière (CVV)
Rendu final attendu : carte à gauche, formulaire à droite
⏱ Durée : 2h 📊 Barème : 50 points

🎯 Contexte

Vous devez réaliser une interface de paiement interactive dans laquelle une carte bancaire se remplit en temps réel pendant que l'utilisateur saisit ses informations dans un formulaire. La carte doit se retourner pour afficher le CVV au dos lorsqu'on clique dans le champ correspondant.

🚫 Contraintes techniques imposées

Interdit Remplacé par
addEventListener Attributs HTML (oninput, onfocus, onblur)
classList.add/remove element.style.transform ou input.className
event.target Passage de this en paramètre
::before / ::after <div> décoratives dédiées
Regex (/\d/, /\s/…) Boucles for + charCodeAt
slice, substring, trim, split, join, parseInt, padEnd, replace Boucles for / while

💡 Indices

  • Retournement 3D : perspective sur le parent, transform-style: preserve-3d sur la carte.
  • Codes ASCII : '0'=48, '9'=57, 'A'=65, 'Z'=90, 'a'=97, 'z'=122.
  • Nettoyage des espaces : drapeau dernierEtaitEspace initialisé à true.
  • Troncature : for (let i = 0; i < texte.length && i < max; i++).
  • Réécriture : input.value = nouvelleValeur supprime les caractères excédentaires.
  • Espace final au blur : ne pas supprimer l'espace final pendant la frappe, sinon impossible de taper un second mot.
