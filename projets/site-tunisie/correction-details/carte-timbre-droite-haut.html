1

Bannière avec image de fond et voile semi-transparent

Superposer un calque sombre (.voile) entre l'image de fond et le texte (.contenu)

header-details.html
Code CSS & HTML
CSS + HTML 
<style>
  .fond {
    height: 400px;
    position: relative;
    background: url("../images/nord.jpg") center / cover no-repeat;
  }

  .voile {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: #0f1c47;
    opacity: 0.86;
  }

  .contenu {
    position: relative;
    color: aliceblue;
    display: flex;
    justify-content: center;
  }
</style>

<div class="fond">
  <div class="voile"></div>

  <div class="contenu">
    <h1>Bienvenue</h1>
    <p>Mon texte</p>
  </div>
</div>
💡 Principe de superposition : Le parent .fond est en position: relative pour servir de repère. Le .voile en position: absolute couvre toute la surface, et .contenu en position: relative passe automatiquement au-dessus du voile.
.fond (position: relative) │ ├── .voile ← bleu (#0f1c47) + opacity (0.86) en position: absolute │ └── .contenu ← texte au-dessus (position: relative + color: aliceblue)

Carte image avec badge promo en haut à droite

Positionner une étiquette inclinée (.badge-promo) sur le coin d'un conteneur (.hero-img)

carte-timbre-droite-haut.html
Code CSS & HTML
CSS + HTML 
<style>
  .hero-img {
    width: 300px;
    height: 500px;
    position: relative;
  }
  .hero-img img {
    width: 100%;
    border-radius: 20px;
    background: #fff;
    padding: 10px;
    box-shadow: 0 15px 30px rgba(15, 28, 71, 0.25);
  }
  .badge-promo {
    position: absolute;
    top: -10px;
    right: -10px;
    background: #e2691a;
    color: #fff;
    padding: 6px 14px;
    border-radius: 999px;
    font-size: 12px;
    font-weight: 800;
    transform: rotate(8deg);
    box-shadow: 0 5px 15px rgba(0, 0, 0, 0.25);
  }
</style>

<div class="hero-img">
  <img
    src="../images/carte-tunisie.png"
    alt="Carte stylisée de la Tunisie"
    title="La Tunisie, du Nord au Sud"
  />
  <span class="badge-promo"> 3 régions</span>
</div>
💡 Points clés à retenir : • position: relative sur .hero-img sert d'ancre au badge.
• top: -10px; right: -10px; fait légèrement déborder le badge sur le coin supérieur droit.
• border-radius: 999px crée la forme pilule et transform: rotate(8deg) donne l'effet timbre incliné.

Encadré <fieldset> avec <legend> animé au survol

Créer un bloc encadré avec un titre surélevé qui s'anime au passage de la souris (:hover + translateY)

fieldset-legend.html
Code CSS & HTML
CSS + HTML 
<style>
  .bloc {
    background: white;
    border: 2px solid #4f46e5;
    border-radius: 12px;
    padding: 25px;
  }

  .bloc legend {
    color: white;
    background: #4f46e5;
    border: 2px solid #4f46e5;
    border-radius: 8px;
    padding: 6px 15px;
    font-weight: bold;
    transition: 0.3s;
  }

  .bloc legend:hover {
    transform: translateY(-4px);
  }
</style>

<fieldset class="bloc">
  <legend>🗺️ La carte chargée dans un iframe</legend>

  <p>Contenu du bloc...</p>
</fieldset>
💡 Points clés à retenir : • La balise <legend> se place automatiquement à cheval sur la bordure haute de son parent <fieldset>.
• transition: 0.3s associée à transform: translateY(-4px) sur :hover soulève doucement le titre vers le haut au survol.
