Activité 1 : Découverte des méthodes de l'objet Date

Taper et exécuter le script suivant, puis préciser le rôle de chaque méthode employée :

function Tester() {
  var d = new Date();
  alert(d); alert(d.getDay()); alert(d.getMonth()); alert(d.getFullYear());
  alert(d.getHours()); alert(d.getMinutes()); alert(d.getSeconds());
  alert(d.getTime()); alert(d.getDate()); alert(Date.now());
}

Activité 2 : Calcul d'Âge et Prochain Anniversaire

Créer un formulaire permettant à l'utilisateur de saisir sa date de naissance. Au clic sur le bouton "Calculer", afficher :

  • Son âge exact en années.
  • Le nombre de jours restants avant son prochain anniversaire.

Activité 4 : Jeu de Devinette

Concevoir une interface interactive pour un jeu de devinette :

  1. L'utilisateur saisit un nombre $N$ d'éléments ($6 \le N \le 10$).
  2. Le programme génère un tableau de $N$ entiers aléatoires uniques compris entre 1 et 100, puis affiche le Min et le Max.
  3. L'utilisateur devine un nombre : la page indique la liste générée et affiche "Vous avez gagné" ou "Vous avez perdu".

Activité 5 : Calculateur d'IMC

Créer une interface calculant l'Indice de Masse Corporelle ($\text{IMC} = \text{Poids} / \text{Taille}^2$) et affichant le bilan médical. Assurer le contrôle de saisie des données numériques.

Activité 6 : Générateur Automatique de Mot de Passe (Sans Regex)

Créer un formulaire d'inscription. Contrôler l'adresse e-mail en utilisant uniquement les méthodes de l'objet String :

  • Contient un seul symbole `@`.
  • L'identifiant comporte au moins 6 caractères, contient exactement un point `.`, et commence/finit obligatoirement par une lettre.

Calcul du mot de passe : ch1 + ch2 + ch3 + posPoint (avec ch1 = Année de naissance, ch2 = Identifiant en majuscules, ch3 = ch2 avec dernier caractère remplacé par 'F', et posPoint = indice du dernier point de l'e-mail).

Activité 7 : Correction Automatique d'Examen

Concevoir la page Examen.html (CIN, Nom, Prénom, 3 questions QCM). La fonction verif() doit :

  • Vérifier sans Regex que le CIN comprend 8 chiffres exacts et que Nom/Prénom contiennent uniquement des lettres.
  • Calculer et afficher dans un message le nombre de réponses correctes et incorrectes.

Activité 8 : Calculateur de Moyenne STI

Calculer la moyenne trimestrielle ($\text{Moy} = \frac{\text{DC1} + \text{DC2} + 2 \times \text{DS}}{4}$) et afficher automatiquement la mention.
