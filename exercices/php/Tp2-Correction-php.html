Corrigé de la Série : Les fonctions relatives aux chaînes de caractères

Correction des Exercices

  1. Exercice 1 : Nettoyage, longueur et casse d'une chaîne 
    <?php
$chaine = "  Developpement Web  ";

// 1. Supprimer les espaces superflus (trim)[cite: 9]
$chaine_epuree = trim($chaine);
echo "Chaîne épurée : " . $chaine_epuree . "<br>";

// 2. Longueur de la chaîne (strlen)[cite: 9]
echo "Longueur : " . strlen($chaine_epuree) . "<br>";

// 3. En majuscules (strtoupper) et minuscules (strtolower)[cite: 9]
echo "Majuscules : " . strtoupper($chaine_epuree) . "<br>";
echo "Minuscules : " . strtolower($chaine_epuree) . "<br>";
?>
  2. Exercice 2 : Extraction, inversion et recherche de position 
    <?php
$ch = "Programmation";

// 1. Extraire "gramme" (substr : position 3, longueur 6)[cite: 9]
$extrait = substr($ch, 3, 6);
echo "Extrait : " . $extrait . "<br>";

// 2. Inverser l'ordre des caractères (strrev)[cite: 9]
$inverse = strrev($ch);
echo "Chaîne inversée : " . $inverse . "<br>";

// 3. Trouver la position de la première occurrence de "m" (strpos)[cite: 9]
$pos = strpos($ch, "m", 0);
echo "Position de 'm' : " . $pos . "<br>";
?>
  3. Exercice 3 : Remplacement de caractères 
    <?php
$phrase = "La programmation en PHP est utile";

// Remplacer 'a' par 'e' (str_replace)[cite: 9]
$resultat = str_replace("a", "e", $phrase);
echo "Résultat : " . $resultat;
?>
  4. Exercice 4 : Comparaison de chaînes (avec et sans casse) 
    <?php
$str1 = "Informatique";
$str2 = "informatique";

// 1. Comparaison sensible à la casse (strcmp)[cite: 9]
$comp1 = strcmp($str1, $str2);
echo "Comparaison (strcmp) : " . $comp1 . "<br>";

// 2. Comparaison insensible à la casse (strcasecmp)[cite: 9]
$comp2 = strcasecmp($str1, $str2);
echo "Comparaison (strcasecmp) : " . $comp2 . "<br>";
?>
  5. Exercice 5 : Fonctions ASCII (chr et ord) 
    <?php
// 1. Caractère à partir du code ASCII 65 (chr)[cite: 9]
$car = chr(65);
echo "Le caractère pour le code ASCII 65 est : " . $car . "<br>";

// 2. Valeur ASCII du premier caractère de 'B' (ord)[cite: 9]
$code = ord('B');
echo "La valeur ASCII de 'B' est : " . $code;
?>
