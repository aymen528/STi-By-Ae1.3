Corrigé de la Série de Révision : Gestion d'un Hôtel (Gesthotel)[cite: 11]

Correction des Requêtes SQL

  1. Afficher tous les Clients d'Ariana : 
    SELECT * 
FROM client 
WHERE adresse = 'ariana';
  2. Donner le nombre de chambres par type de chambre : 
    SELECT type, COUNT(*) AS nb_chambre 
FROM chambre 
GROUP BY type;
  3. Trouver les chambres qui coûtent le moins cher : 
    SELECT * 
FROM chambre 
WHERE prix = (SELECT MIN(prix) FROM chambre);
  4. Afficher une liste qui comprend le numéro de réservation, la date d'entrée et le nom du client : 
    SELECT r.numr, dateDebut, nom 
FROM client cl, reservation r 
WHERE r.numcl = cl.numcl;
  5. Afficher une liste qui comprend le numéro de réservation et le nom du client pour les entrées :
    • 5.1 d'aujourd'hui (date de début de réservation = date système) : 
      SELECT numr, nom 
FROM client cl, reservation r 
WHERE r.numcl = cl.numcl 
AND DATE(dateDebut) = DATE(NOW());
    • 5.2 passées au cours des 7 derniers jours : 
      SELECT numr, nom 
FROM client cl, reservation r 
WHERE r.numcl = cl.numcl 
AND DATE(dateDebut) >= DATE_SUB(NOW(), INTERVAL 7 DAY);
    • 5.3 passées il y a plus de 30 jours : 
      SELECT numr, nom 
FROM client cl, reservation r 
WHERE r.numcl = cl.numcl 
AND DATE(dateDebut) < DATE_SUB(NOW(), INTERVAL 30 DAY);
  6. Calculer le prix moyen des chambres : 
    SELECT AVG(prix) AS prix_moyenne 
FROM chambre;
  7. Calculer le prix moyen des chambres par type de chambre : 
    SELECT AVG(prix) AS prix_moyenne, type 
FROM chambre 
GROUP BY type;
  8. Lister toutes les réservations du client C103 : 
    SELECT * 
FROM reservation 
WHERE numcl = 'CL03';
  9. Calculer le montant total de la facture en cours du client C103[cite: 11] : 
    SELECT numcl, SUM(prix * nbjours) AS facture 
FROM reservation R, chambre ch 
WHERE ch.numch = R.numch 
AND R.numcl = 'CL03' 
GROUP BY numcl;
  10. Lister les noms des clients résidant actuellement à l'hôtel : 
    SELECT nom 
FROM client C, reservation R 
WHERE C.numcl = R.numcl 
AND DATE(dateDebut) + nbjours >= DATE(NOW()) 
AND DATE(dateDebut) <= DATE(NOW());
  11. Donner le nombre de clients qui ont choisi les mêmes pensions que le client CI02 : 
    SELECT COUNT(DISTINCT numcl) AS nbrclient 
FROM reservation 
WHERE pension = (SELECT pension FROM reservation WHERE numcl = 'CL02');
  12. Afficher les réservations dont le séjour est supérieur à la moyenne des séjours : 
    SELECT * 
FROM reservation 
WHERE nbjours > (SELECT AVG(nbjours) FROM reservation);
  13. Afficher les réservations dont le séjour est supérieur à celui de numr = 2 : 
    SELECT * 
FROM reservation 
WHERE nbjours > (SELECT nbjours FROM reservation WHERE numr = 2);
  14. Donner le nombre de réservations faites pour des chambres simples : 
    SELECT COUNT(*) AS nbchambre 
FROM reservation R, chambre ch 
WHERE R.numch = ch.numch 
AND type = 'S';
  15. Calculer le nombre total de nuitées par chambre : 
    SELECT SUM(nbjours) AS nbrnuits, numch 
FROM reservation 
GROUP BY numch;
  16. Calculer le chiffre d'affaires total par chambre (= total des nuitées * prix) : 
    SELECT SUM(nbjours) * prix AS chiffre_affaire, R.numch 
FROM reservation R, chambre ch 
WHERE R.numch = ch.numch 
GROUP BY R.numch, prix;
  17. Afficher le nombre de réservations par client et pension : 
    SELECT numcl, pension, COUNT(*) AS nbreservation 
FROM reservation 
GROUP BY numcl, pension;
  18. Lister les chambres dans l'ordre croissant des types et l'ordre décroissant des prix : 
    SELECT * 
FROM chambre 
ORDER BY type, prix DESC;
  19. Lister les clients ayant effectué au moins 2 réservations : 
    SELECT cl.numcl, nom, adresse, COUNT(numr) AS nbreservation 
FROM client cl, reservation r 
WHERE cl.numcl = r.numcl 
GROUP BY cl.numcl, nom, adresse 
HAVING COUNT(numr) >= 2;
  20. Lister les chambres n'ayant aucune réservation enregistrée dans la base : 
    SELECT * 
FROM chambre 
WHERE numch NOT IN (SELECT numch FROM reservation);
