📌 Partie 1 – QCM SQL général (5 points)
Q1. Quelle est la clé primaire de la table NOTES ?
✅ Réponse correcte : C) (Numetu, Numat)
Explication : La table NOTES enregistre les notes des étudiants dans chaque matière. Un étudiant (Numetu) ne peut avoir qu'une seule note par matière (Numat). La clé primaire est donc une clé composite formée par les deux colonnes (Numetu, Numat).
Q2. Que retourne DATEDIFF('2025-01-01', Dtnaiss) ?
✅ Réponse correcte : C) Jours
Explication : La fonction DATEDIFF retourne la différence entre deux dates en nombre de jours. Pour obtenir l'âge, on divise par 365.25 (années incluant les années bissextiles).
Q3. HAVING COUNT(Note) = (SELECT COUNT(*) FROM MATIERE) permet de :
✅ Réponse correcte : B) Étudiants avec note dans toutes les matières
Explication : La sous-requête compte le nombre total de matières. La condition HAVING vérifie que l'étudiant a autant de notes que de matières, donc qu'il a une note dans chaque matière.
Q4. Différence IN / EXISTS ?
✅ Réponse correcte : C) IN compare des valeurs, EXISTS teste l'existence de lignes
Explication :
  • IN : Compare une valeur à une liste de valeurs (peut être une sous-requête)
  • EXISTS : Teste si une sous-requête retourne au moins une ligne
  • EXISTS est souvent plus performant pour de grands volumes car il s'arrête dès qu'une ligne est trouvée
Q5. Pourquoi sous-requête corrélée dans requête14 (meilleure note) ?
✅ Réponse correcte : B) Meilleure note par matière
Explication : La sous-requête corrélée s'exécute pour chaque matière et trouve la note maximale de cette matière spécifique. Elle est "corrélée" car elle fait référence à la matière de la requête principale.
🗄️ Partie 2 – LDD (Langage de Définition des Données) (8 points)
Q1. Que signifie l'acronyme LDD ?
✅ Réponse : Langage de Définition des Données (Data Definition Language - DDL)
Le LDD est le sous-ensemble du SQL qui permet de définir la structure de la base de données (création, modification, suppression des tables, indexes, contraintes, etc.).
Q2. Citez 3 commandes du LDD.
✅ Réponse : CREATE, ALTER, DROP, TRUNCATE, RENAME
  • CREATE : Créer une table, un index, une vue, une base
  • ALTER : Modifier la structure d'une table (ajouter/supprimer colonnes, contraintes)
  • DROP : Supprimer définitivement une table ou un objet
  • TRUNCATE : Vider toutes les données d'une table (plus rapide que DELETE)
  • RENAME : Renommer une table ou une colonne
Q3. Créer la table MATIERE (Numat INT, Nomat VARCHAR(50), Coeff INT, Numens INT).
CREATE TABLE MATIERE (
    Numat INT PRIMARY KEY,
    Nomat VARCHAR(50),
    Coeff INT,
    Numens INT,
    FOREIGN KEY (Numens) REFERENCES ENSEIGNANT(Numens)
);
Explication : La clé primaire est Numat. On ajoute une contrainte de clé étrangère pour lier chaque matière à son enseignant.
Q4. Ajouter une colonne 'DateEvaluation' à la table NOTES.
ALTER TABLE NOTES ADD COLUMN DateEvaluation DATE;
La commande ALTER TABLE avec ADD COLUMN ajoute une nouvelle colonne. La colonne sera NULL pour les enregistrements existants.
Q5. Différence entre DROP et TRUNCATE ?
✅ DROP supprime la table et sa structure, TRUNCATE supprime uniquement les données
  • DROP TABLE : Supprime la table et sa structure (schéma, contraintes). La table n'existe plus.
  • TRUNCATE TABLE : Supprime toutes les lignes mais conserve la structure (colonne, contraintes).
  • TRUNCATE est plus rapide que DELETE car il ne génère pas de logs ligne par ligne.
Q6. Modifier le type de 'Note' de INT à DECIMAL(5,2).
ALTER TABLE NOTES MODIFY COLUMN Note DECIMAL(5,2);
DECIMAL(5,2) permet des notes avec 2 décimales (ex: 15.50). Le (5,2) signifie 5 chiffres au total dont 2 après la virgule (max 999.99).
Q7. Supprimer la contrainte de clé étrangère sur Numens dans MATIERE.
ALTER TABLE MATIERE DROP FOREIGN KEY fk_matiere_enseignant;
Pour supprimer une clé étrangère, il faut connaître son nom. La syntaxe peut varier selon les SGBD : DROP CONSTRAINT nom_contrainte ou DROP FOREIGN KEY nom_contrainte.
Q8. Créer une vue 'VueMoyennes' affichant Numetu et moyenne générale.
CREATE VIEW VueMoyennes AS
SELECT Numetu, AVG(Note) as MoyenneGenerale
FROM NOTES
GROUP BY Numetu;
Une vue est une table virtuelle basée sur une requête. Elle simplifie les accès aux données et peut servir de couche de sécurité en masquant certaines colonnes.
✏️ Partie 3 – SQL à compléter (5 points)
Exercice 1 : Afficher nom et date naissance des étudiants nés après 01/01/2010.
SELECT Nometu, Dtnaiss
FROM ETUDIANT
WHERE Dtnaiss > '2010-01-01';
La condition WHERE Dtnaiss > '2010-01-01' filtre les étudiants nés après cette date. Les dates en SQL se comparent directement avec les opérateurs >, <, =.
Exercice 2 : Nombre d'étudiants par sexe.
SELECT Cdsexe, COUNT(*) AS NbEtudiants
FROM ETUDIANT
GROUP BY Cdsexe;
GROUP BY Cdsexe regroupe les étudiants par sexe, et COUNT(*) compte le nombre dans chaque groupe.
Exercice 3 : Étudiants avec note >15 en Mathématiques.
SELECT Nometu
FROM ETUDIANT
WHERE Numetu IN (
    SELECT Numetu
    FROM NOTES N, MATIERE M
    WHERE N.Numat = M.Numat
      AND M.Nomat = 'Mathématiques'
      AND N.Note > 15
);
La sous-requête trouve les Numetu des étudiants ayant une note >15 en Maths. La requête principale sélectionne leurs noms.
Exercice 4 : Matières avec moyenne >=12.
SELECT M.Nomat, AVG(N.Note) AS Moyenne
FROM MATIERE M, NOTES N
WHERE M.Numat = N.Numat
GROUP BY M.Nomat
HAVING AVG(N.Note) >= 12;
HAVING s'utilise pour filtrer sur les résultats d'agrégation (AVG, SUM, COUNT). WHERE filtre avant agrégation.
Exercice 5 : Enseignants qui enseignent au moins 2 matières.
SELECT E.Nomens, COUNT(M.Numat) AS NbMatieres
FROM ENSEIGNANT E, MATIERE M
WHERE E.Numens = M.Numens
GROUP BY E.Numens, E.Nomens
HAVING COUNT(M.Numat) >= 2;
La clause HAVING COUNT(M.Numat) >= 2 ne retient que les enseignants ayant au moins 2 matières dans leur groupe.
✅❌ Partie 4 – Vrai / Faux (5 points)
1. SELECT * FROM ETUDIANT WHERE Cdsexe='H' affiche tous les garçons.
✅ VRAI
'H' désigne le sexe masculin (Garçon) dans la table SEXE.
2. DISTINCT permet d'éliminer les doublons.
✅ VRAI
DISTINCT s'utilise après SELECT pour supprimer les lignes en double.
3. WHERE peut contenir AVG().
❌ FAUX
WHERE ne peut pas contenir de fonctions d'agrégation comme AVG(), SUM(), COUNT(). C'est le rôle de HAVING pour filtrer après GROUP BY.
4. Une sous-requête corrélée s'exécute pour chaque ligne principale.
✅ VRAI
Une sous-requête corrélée dépend de la ligne courante de la requête principale, elle s'exécute donc une fois par ligne.
5. LEFT JOIN retourne uniquement les lignes avec correspondances.
❌ FAUX
LEFT JOIN retourne toutes les lignes de la table de gauche, même si aucune correspondance n'existe dans la table de droite (valeurs NULL).
💭 Partie 5 – Réflexion (7 points)
1. Modifier requête 11 pour éviter les doublons (chaque couple une fois).
SELECT DISTINCT
    LEAST(G.Nometu, F.Nometu) AS Nom1,
    GREATEST(G.Nometu, F.Nometu) AS Nom2
FROM ETUDIANT G, ETUDIANT F
WHERE G.Cdsexe = 'H' AND F.Cdsexe = 'F'
  AND ABS(DATEDIFF(G.Dtnaiss, F.Dtnaiss)) <= 180
  AND G.Nometu < F.Nometu;
On ajoute G.Nometu < F.Nometu pour éviter les doublons (Alice/Benoit et Benoit/Alice).
2. Que se passe-t-il requête7 si étudiant sans note ? Correction ?
L'étudiant est exclu car il n'a pas de ligne dans NOTES
La requête utilise une jointure implicite avec NOTES. Les étudiants sans note n'apparaissent pas. Pour les inclure avec moyenne NULL, utiliser LEFT JOIN.
3. Trouver l'étudiant avec meilleure moyenne générale.
SELECT E.Nometu,
    SUM(N.Note * M.Coeff)/SUM(M.Coeff) AS Moyenne
FROM ETUDIANT E, NOTES N, MATIERE M
WHERE E.Numetu = N.Numetu AND N.Numat = M.Numat
GROUP BY E.Numetu, E.Nometu
ORDER BY Moyenne DESC
LIMIT 1;
4. Mettre à jour coefficient 'Informatique' à 4.
UPDATE MATIERE SET Coeff = 4 WHERE Nomat = 'Informatique';
5. Supprimer enseignants sans matière.
DELETE FROM ENSEIGNANT
WHERE Numens NOT IN (SELECT DISTINCT Numens FROM MATIERE);
6. Ajouter une contrainte CHECK sur Note (entre 0 et 20).
ALTER TABLE NOTES
ADD CONSTRAINT ck_note CHECK (Note BETWEEN 0 AND 20);
La contrainte CHECK garantit que les notes insérées sont valides (entre 0 et 20).
7. Créer un index sur Nometu dans la table ETUDIANT.
CREATE INDEX idx_nometu ON ETUDIANT(Nometu);
Un index accélère les recherches sur la colonne Nometu (recherche par nom). Il ralentit en revanche les INSERT/UPDATE.

💡 Conseil : Pour réussir une épreuve SQL, maîtrisez les 3 sous-langages :
- LDD : CREATE, ALTER, DROP (structure)
- LMD : SELECT, INSERT, UPDATE, DELETE (données)
- LTD : BEGIN, COMMIT, ROLLBACK (transactions)
