Création et modification de la structure de la base de données

Exercice 1 : Système d'Information d'un Hôpital

La base de données d'un hôpital contient entre autres les tables suivantes : Patient, Medecin, Sejour, traite . La structure des différentes tables est la suivante :

Table Patient

Colonne Type Taille Contraintes
num_patient Numérique 10 Clé primaire
nom_patient Texte 20 Non nulle
prenom_patient Texte 20 Non nulle
adr_patient Texte 50

Table Medecin

Colonne Type Taille Contraintes
code med Texte 10 Clé primaire
nom med Texte 20 Non nulle
prenom_med Texte 20 Non nulle
tel med Numérique 8
specialite Texte 12 Valeurs possibles : généraliste, chirurgien

Table Sejour

Colonne Type Taille Contraintes
num_sej numérique (auto_incrément) Clé primaire
num chambre Numérique 4 Non nulle, entre 1 et 1000
date deb Date Non nulle et ≤ date d'aujourd'hui
date fin Date ≤ date d'aujourd'hui et > date_deb
num_patient Numérique 10

Table traite

Colonne Type Taille Contraintes
num_patient Numérique 10 Clé primaire
date deb trait date ≤ date aujourd'hui
code med Texte 10 Clé primaire

Questions : Donner les commandes SQL qui permettent de :

  1. Créer la structure des quatre tables ci-dessus, en respectant les contraintes d'intégrité .
  2. Ajouter la colonne "Age" dans la table Patient tel que : Type : Numérique, Taille : 2, Contrainte : Non nulle et ≥ 1 .
  3. Modifier la colonne "tel_med" de la table medecin tel que : type : texte, taille : 15 .
  4. Supprimer la colonne "tel_med" de la table medecin .
  5. Ajouter la contrainte de clé étrangère entre "num_patient" de la table Patient (table mère) et "num_patient" de la table Sejour (table fille) .
  6. Ajouter la valeur par défaut "Tunis" à la colonne "adr_patient" de la table Patient .

Exercice 2 : Agence de Location de Voitures

Soit la description textuelle de la base de données d'une agence de location de voitures : Client, Vehicule, Location .

Créer les tables "Client", "Vehicule" et "Location" en spécifiant les types de données et les contraintes d'intégrité énoncées dans les tableaux ci-dessous :

Table Client

Nom de colonne Type de données Contraintes
NCIN Cli Texte(8) Clé primaire
Nom Cli Texte(20) Obligatoire
Prenom Cli Texte(20) Obligatoire
Adresse Cli Texte(50)
Ville Texte(20)

Table Vehicule

Nom de colonne Type de données Contraintes
Immat vehicule Texte(10) Clé primaire
Marque Texte(20) Obligatoire et prend l'une des valeurs suivantes : {"Peugeot", "BYD", "Fiat", "Opel", "Volkswagen", "Citroën"}
Model Texte(20) Obligatoire
Annee Acq année obligatoire

Table Location

Nom de colonne Type de données Contraintes
Immat vehicule
NCIN Cli		 Texte(10)
Texte(8)		 Clé primaire
Date Loc Date Par défaut la date d'aujourd'hui, ≤ date d'aujourd'hui
Duree Loc Numérique > 0
Cout Loc Numérique > 0

Questions :

  1. Créer la base de données "Gestion_Location" .
  2. Créer les trois tables Client, Vehicule et Location .
  3. Modification de la structure d'une table :
    • a. Ajouter à la table Client un champ nommé Tel_Cli de type texte et de taille égale à 10 .
    • b. Modifier le type de donnée de la colonne "Tel_Cli" de la table "Client" en numérique de 8 chiffres .
    • c. Supprimer la colonne "Adresse_Cli" dans la table "Client".
    • d. Vérifier que les valeurs de "Annee_Acq" dans la table "Vehicule" sont entre 2010 et 2026 .
    • e. Modifier la clé primaire actuelle de la table Location par la clé primaire composée suivante : Immat_Vehicule, NCIN_Cli, Date_Loc .
    • f. Supprimer la clé primaire de la table "Client" .
    • g. Désactiver la contrainte de clé primaire de la table "Location" .
    • h. Réactiver cette même contrainte .
    • i. Renommer la table "Vehicule" en "Voiture" .
    • j. Supprimer la table "Client" .
    • k. Supprimer la base de données "Gestion_Location" .
N.B. : Pour attribuer la date d'aujourd'hui comme valeur par défaut, il faut utiliser le type "timestamp" sinon ça ne marche pas avec le type date .
