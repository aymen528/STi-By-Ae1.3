sans background-image
background-image

Par défaut, une boîte n’a qu’une couleur de fond. Avec background-image: url(...), on place une image derrière le contenu de la boîte.

L’image part du coin haut-gauche de la boîte. Elle n’est ni redimensionnée ni répétée pour l’instant : c’est la suite du cours.

repeat (défaut)
no-repeat
repeat-x
repeat-y

background-repeat: repeat est la valeur par défaut : l’image se répète en mosaïque jusqu’à remplir toute la boîte.

no-repeat : une seule image. repeat-x : répétée seulement en largeur. repeat-y : seulement en hauteur.

auto
contain
cover
100% 100%

background-size: auto : l’image garde sa taille d’origine (ici 160 × 100 px), quitte à ne pas couvrir toute la boîte.

contain : l’image entière est visible, quitte à laisser du vide. cover : la boîte est entièrement couverte, quitte à rogner l’image.

Avec des mesures, c’est précis : 100% 100% étire l’image aux dimensions exactes de la boîte… au risque de la déformer.

border-box (défaut)
padding-box
content-box
STI
clip: text (bonus)

background-clip décide jusqu’où le fond s’étend. Par défaut (border-box), il passe sous la bordure.

padding-box : le fond s’arrête à la bordure, il ne passe pas dessous. La bordure en pointillés laisse voir la page.

content-box : le fond ne couvre que le contenu, le padding reste transparent.

Bonus moderne : background-clip: text avec color: transparent… le fond peint le texte lui-même !

Bienvenue

background: #27496d url("paysage.svg") no-repeat center / cover;

Chaque propriété existe séparément… mais le raccourci background permet de tout écrire en une seule déclaration.

Dans le raccourci, background-size ne peut s’écrire qu’après background-position, séparé par une barre oblique : center / cover.

Attention : le raccourci réinitialise les propriétés omises à leur valeur initiale. Oublier repeat… et c’est repeat qui s’applique quand même !

a:linkjamais visité a:visiteddéjà visité a:hoversurvolé a:activeen cours de clic

Un vrai lien pour essayer : survole-moi, puis clique-moi

Ordre des règles : a:link → a:visited → a:hover → a:active  (LoVe / HAte)

Un lien <a> possède quatre états : link (jamais visité), visited (déjà visité), hover (survolé à la souris), active (pendant le clic).

On les cible avec les pseudo-classes a:link, a:visited, a:hover et a:active. Testez le vrai lien ci-dessus !

L’ordre des règles est capital : Link → Visited → Hover → Active (mnémotechnique : LoVe / HAte). Sinon, hover et active peuvent être écrasés.

box-shadow

box-shadow : deux mesures d’abord — le décalage horizontal puis le décalage vertical — et enfin la couleur de l’ombre.

Une troisième mesure ajoute le flou (blur). Une quatrième mesure, le spread, agrandit l’ombre comme un anneau.

Le mot-clé inset creuse l’ombre vers l’intérieur, et plusieurs ombres se combinent avec de simples virgules.

STI

text-shadow fonctionne comme box-shadow : décalage horizontal, vertical, puis flou et couleur — mais appliqués au texte.

Pas de spread pour le texte, mais des ombres superposées avec des virgules pour créer une lueur… effet néon garanti.

AE

Le raccourci border regroupe trois valeurs : épaisseur, style (solid, dashed, dotted…) et couleur.

border-radius arrondit les angles : une seule mesure suffit pour les quatre coins.

Avec border-radius: 50%, le carré devient un cercle — et une pastille si la boîte est plus large que haute.

table-layout: fixed

Par défaut, chaque cellule possède sa propre bordure : border-collapse: separate, avec un espace entre elles.

border-collapse: collapse fusionne les bordures voisines en un seul trait : c’est le rendu classique des tableaux.

table-layout: fixed : les largeurs des colonnes suivent la première ligne et la largeur fixée ; le contenu ne pousse plus le tableau.

list-style-type choisit la puce : disc (par défaut), square, circle, decimal, none…

À vous de jouer : répondez aux quatre questions pour valider l’étape !

1. Pour voir l’image entière dans la boîte, sans jamais la rogner :

contain montre toute l’image, quitte à laisser du vide.

cover rogne l’image pour couvrir la boîte ; c’est contain qu’il fallait choisir.

2. Dans quel ordre déclarer les pseudo-classes d’un lien ?

Link → Visited → Hover → Active : le fameux LoVe / HAte.

Le mauvais ordre peut écraser hover et active : c’est link, visited, hover, active.

3. Pour fusionner les bordures d’un tableau en un seul trait :

collapse fusionne les bordures voisines en un seul trait.

table-layout gère les largeurs ; la fusion des bordures, c’est border-collapse: collapse.

4. Dans le raccourci background, background-size s’écrit…

position / size : center / cover, avec la barre oblique entre les deux.

Il est accepté, mais uniquement après background-position, séparé par une barre oblique.
